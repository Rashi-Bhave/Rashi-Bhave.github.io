About

I like building AI that does things: agents that plan, use tools, recover when the world changes under them, and know when they're not sure.

Over the last few years I've taken agentic ML from prototype to production: computer-use agents for web automation, self-healing automation that survives UI changes, multi-agent planners, and retrieval systems used across client deployments.

Before that, I was a Research Fellow at Microsoft Research India, building ReAct-style LLM agents that diagnose outages in Azure data centers and using RL to give them calibrated confidence. Now I'm at CMU, TA-ing GenAI, working with the TEEL Lab, and going deeper into agents, reasoning, and evaluation.
